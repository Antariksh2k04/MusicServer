## Implemented experiment boundary

`DiagnosticNativeSessions` and `/api/v1/diagnostics/native` are registered only when explicit Development diagnostics are enabled. Existing loopback middleware covers all native routes; the server binding stays loopback. Issuance requires the configured operator key. Native routes reject browser Origin/cookies; browser endpoints reject bearer ambiguity and keep CSRF protection. Native access defaults to 30 seconds, with rotating hashed refresh authority and the configured absolute diagnostic session TTL (default 1,800 seconds). Old refresh reuse revokes its family; lineage is capped at 128 rotations and 32 active families. Server restart invalidates this temporary authority, as with the fixture catalog.

Native list/detail/full/HEAD/ranges share the existing catalog/range component. Native logout revokes by refresh authority after access expiry; the CSRF-protected browser operator can revoke all diagnostic native sessions. There is no Android upload feature in this prototype: the existing browser uploads the fixtures for the native investigation.

`src/web/android/app/src/debug/` contains one Media3 1.11.1 service, its app-private binder/Capacitor plugin, broker, and bounded streaming source. The service explicitly registers its MediaSession for notification/foreground management. It uses Media3 focus/noisy-route handling, cancels transient-focus playback intent for manual resume, limits network playback retries to 1/2/4 seconds, and stops at single-track completion. Trusted system controllers receive play/pause/seek/read commands, without queue/next/previous or media replacement. The service is not exported for external binding; platform media controls use its MediaSession.

The native broker serializes renewal, stores issued authority with Keystore AES-GCM in no-backup app storage, rejects stale session generations, and performs at most one auth retry. Refresh failure clears authority instead of retrying an uncertain rotating token. Logout fences late responses and removes persisted credentials before network revocation. Snapshot diagnostics contain counters/time/instance identity, never tokens or private storage references. Capacitor logging is disabled. Java time support uses `desugar_jdk_libs:2.1.5` for declared min SDK 24.

The Ionic diagnostic entry uses the plugin export injected by pinned Capacitor 8.5.2 (verified against its `JSExport`/native bridge source); there is no JS media engine or credential renewal. Native snapshot subscription stops emitting during activity pause. Selection/lookups and recovery are fenced by native intent; UI snapshots are ordered and logout rejects late library/authenticated snapshots. The checkpoint saves only track ID, position, and timestamp; restoration validates detail and stays paused.

A 45-second native scheduled probe discards the current buffer and reopens at the current position after short access expiry, independent of Ionic. It must be measured on the phone; preparation does not prove renewal/background playback. Pause/seek/logout/new selection cancels it. Use a separate uninterrupted >=15-minute listening check.

Debug-only network security permits HTTP only to literal `127.0.0.1`, reached with `adb reverse`. Release source/manifest omit diagnostic code/service/allowance, and Media3 is a debug dependency. The workflow now builds both APK variants and instrumentation sources, runs native unit tests, and examines the compiled release APK using `apkanalyzer` plus `scripts/check-android-release.cjs`. A new hosted run has not yet executed these steps.
